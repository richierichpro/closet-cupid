# Closet Cupid frontend

React 19 + TypeScript + Vite. The phone app (swipe deck, try-on, round payoffs, matches) and the live board at `/board`.

```bash
npm install
npm run dev        # http://localhost:5173, proxies /api, /images and /tryon to the API on :8000
```

Set `API_URL` to point at a different API server.
